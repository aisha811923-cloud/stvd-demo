# Accessibility Compliance (WCAG 2.1 AA)

## 1. Visual & Contrast Ratios
* Navy (`#0F1E36`) against Parchment (`#F8F9FB`): Ratio **13.5:1** (Passes AAA).
* Gold (`#D4AF37`) used only on dark navy backgrounds for text or as border highlights.

## 2. Keyboard Navigation
* All modal dialogs must trap focus with `Tab` and exit on `Escape`.
* Skip-to-content links provided as the first navigable DOM element (`<a href="#main-content">Skip to Content</a>`).
